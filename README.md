# MedDocDent

## 1. Предметная область
    Система относится к сфере управления учреждениями здравоохранения — поликлиниками, больницами, клиниками. В предметной области учитываются:
    - Кадры медицинского учреждения: врачи разных специальностей, их квалификация, ставки, график допустимой рабочей нагрузки, отпуска и больничные. 
    - Планирование приёма: рабочие и выходные дни, праздничные даты, смены, длительность приёма. 
    - Список пациентов: запись на приём, экстренные случаи. 

## 2. Цели системы
    - Автоматизация составления расписания приёмов и смен врачей с учётом их специализации. 
    - Исключение конфликтов и наложений при просмотре и бронировании сеансов. 
    - Управление записью пациентов: обеспечение удобной записи.

## 4. Основные функции системы
### Управление расписанием
    - Создание, редактирование и удаление рабочих смен врачей.
    - Автоматическая проверка наложений смен у одного врача.
    - Автоматический учёт отпусков, больничных и учебных дней при формировании графика. 
### Управление записью пациентов
    - Поиск свободного слота по специальности или врачу.
    - Запись, перенос и отмена приёма — через администратора или портал пациента. 
### Управление ресурсами
    - Закрепление кабинетов за врачами с учётом специальности и оборудования.  
### Взаимодействие с врачами
    - Личный кабинет врача: просмотр расписания на день / неделю / месяц, список записанных пациентов с краткой информацией.
    - Функция связи с руководством по поводу изменения расписания.

## 5. Архитектура 
    Приложение разработано с использованием многоуровневой архитектуры, что позволяет разграничивать пользовательский интерфейс, сервисный слой и слой баз данных.
    Пользователь
     │
     ▼
Консольный интерфейс
(main.py, menu.py, auth.py)
     │
     ▼
Сервисный слой
(services)
     │
     ▼
Слой доступа к данным
(repositories)
     │
     ▼
База данных
(database)
